# milkproduction
Description:

**The primary table for milk production data. This table should tie to any information about cows, their locations, movement, treatments and, ultimately, datasets produced using the cows as primary data elements. This table is intended to capture the milk production data for each cow, including the date of production, the amount of milk produced, and any relevant metadata about the production process.**

## Columns

|         name         |     type    |                                                                                                                                          comment                                                                                                                                         |
|----------------------|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  *milkproductionid*  |    uuid7    |                                                   A unique identifier for a particular milk production record. This identifier is generated by the system and is used to uniquely identify each milk production record in the database.                                                  |
|        *cadid*       |     text    |                                                                                           This is the unique identifier given to the cow by the Canadian Government that conforms to ISO 11784.                                                                                          |
| *production_datetime*|  datetimetz |                                                                                                               The date and time on which the milk production was recorded.                                                                                                               |
|*instrumentinstanceid*|    uuid7    |A unique identifier for a particular instrument instance. This identifier is generated by the system and is used to uniquely identify each instrument instance in the database. It is a UUID version 7, which provides a high level of uniqueness and is suitable for distributed systems.|
|     *milk_yield*     |numeric(10,2)|                                                                                                                            The volume of milk produced in kg.                                                                                                                            |
|      *milk_flow*     | numeric(5,2)|                                                                                                                            The flow rate of the milk produced.                                                                                                                           |
|   *attachment_time*  |   integer   |                                                                                                                The time taken to attach the milking equipment to the cow.                                                                                                                |
|    *cup_off_time*    |   integer   |                                                                                                               The time taken to detach the milking equipment from the cow.                                                                                                               |
|  *milk_temperature*  | numeric(5,2)|                                                                                                                 The temperature of the milk produced in degrees Celsius.                                                                                                                 |
|  *milk_conductivity* | numeric(5,2)|                                                                                                                     The electrical conductivity of the milk produced.                                                                                                                    |
|      *quarterid*     |   integer   |                                                                The quarter of the cow's udder from which the milk was produced. This is an integer value from 1 to 4, pointing to cow quarters, a small vocabulary table.                                                                |
