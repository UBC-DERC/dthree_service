# farms
Description:

**A table that contains information about the farms in the dairy database. This table is used to store information about the farms, such as their name, location, and other relevant details. Each farm is assigned a unique identifier, and additional information about the farm can be stored in this table.**

## Columns

|     name    |   type  |                                                                     comment                                                                     |
|-------------|---------|-------------------------------------------------------------------------------------------------------------------------------------------------|
|   *farmid*  |  uuid7  |A unique identifier for a particular farm. This identifier is generated by the system and is used to uniquely identify each farm in the database.|
|    *name*   |   text  |                                                              The name of the farm.                                                              |
|*description*|   text  |                                                            A description of the farm.                                                           |
|  *address*  |   text  |                                                             The address of the farm.                                                            |
|  *location* |geography|                                         The geographical location of the farm, represented as a polygon.                                        |

## Constraints

This table has no constraints

## Indexes

This table has no index

**References**
