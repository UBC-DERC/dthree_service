# cattlebreeds
Description:

**This table contains information about the different breeds of cattle.**

## Columns

|        name        | type|                                                                                     comment                                                                                    |
|--------------------|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|      *breedid*     |uuid7|          A unique identifier for a particular breed of cattle. This identifier is generated by the system and is used to uniquely identify each breed in the database.         |
|    *breed_name*    | text|                                                                          The name of the cattle breed.                                                                         |
|    *externalid*    | text|                           A unique external identifier for the cattle breed. This identifier is used to uniquely identify each breed in the database.                          |
|*externaldatabaseid*|uuid7|A unique identifier for the external database from which the breed information was sourced. This identifier is used to uniquely identify each external database in the database.|

## Constraints

This table has no constraints

This table has no index
